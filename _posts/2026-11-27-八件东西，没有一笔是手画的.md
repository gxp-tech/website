 受hairline等距线稿交互动画库(https://hairline.lucasmarkes.com/)启发，才有了本次SVG实验，全程用AI vibe coding实现。基础原理是通过SVG方式 用几何算法实现3d效果，没有贴图，没有 3D 引擎，也没有生成式模型参与，并且每个图形都支持交互式互动。

## 怎么做的

- **正交相机**：`Cam(方位角, k, 缩放)`，k = 0.5 就是 2:1 等轴测。没有透视，平行线永远平行。
- **几何是算出来的**：每个对象是一组参数化的面与线。鲸鱼的两张测绘图放样成一个曲面，蒲公英的种子头是一百多个瘦果。
- **遮挡靠画序**：画家算法，从远到近追加，近的盖住远的。没有深度缓冲。
- **一根线，两套色**：全部描边都是 SVG path，粗细统一，颜色取 CSS 变量，所以深浅主题只换变量。

<script>
(function () {
  var frames = [].slice.call(document.querySelectorAll("iframe[data-hairline]"));
  if (!frames.length) return;

  /* The blog's own palette decides, not the system's. Chirpy stores the choice
     as html[data-mode]; when that is absent the resolved background colour is
     the fallback, so a future theme that renames the attribute still works. */
  function mode() {
    var m = document.documentElement.getAttribute("data-mode");
    if (m === "dark" || m === "light") return m;
    var rgb = getComputedStyle(document.body).backgroundColor.match(/\d+/g);
    if (!rgb || rgb.length < 3) return matchMedia("(prefers-color-scheme: dark)").matches ? "dark" : "light";
    var l = (rgb[0] * 0.299 + rgb[1] * 0.587 + rgb[2] * 0.114) / 255;
    return l < 0.5 ? "dark" : "light";
  }

  /* Same origin, so the figure's html[data-theme] can be set directly: one
     attribute flips its whole palette, no reload, no re-parse. */
  function apply() {
    var m = mode();
    frames.forEach(function (f) {
      try { f.contentDocument.documentElement.dataset.theme = m; } catch (e) {}
    });
  }

  frames.forEach(function (f) { f.addEventListener("load", apply); });
  new MutationObserver(apply).observe(document.documentElement, { attributes: true });
  apply();
})();
</script>
